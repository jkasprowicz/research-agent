# Interfaces Final Editorial Decision

## Editorial role decision

Decision: `Return before review / Not ready for submission in current form`

## Rationale

As a managing-editor style assessment, the main barrier is not the scientific theme. The manuscript is broadly compatible with Revista Interfaces in topic, tone, and level of technical complexity. The barrier is technical compliance.

The most important issues are:

1. The manuscript currently appears to have `10` pages, while the journal-oriented requirements already documented in the repository indicate an expected range of `12 to 20` pages.
2. Continuous line numbering was not detected in the Word document.
3. Final rendered page numbering was not fully confirmed in this environment.
4. Final figure-package conformity for journal upload was not verified.

These are the kinds of issues that commonly trigger a return to authors before peer review in Brazilian journals with explicit formatting rules.

## Scientific decision

If the manuscript were judged only on scientific scope and writing maturity for this journal, it would likely be considered suitable for peer review. The current version is:

- coherent
- cautious
- interdisciplinary
- appropriate for exploratory health informatics

However, suitability for peer review is not the same as readiness for immediate submission.

- `55-70%`

Main drivers:

- apparent page-count noncompliance
- missing continuous line numbering
- unresolved technical formatting checks

`Probability of being sent to peer review if technical issues are corrected`

## Final recommendation

Do not treat the manuscript as ready for immediate submission to Revista Interfaces.

Use the current text as a strong near-final scientific version, but complete the remaining editorial requirements before submission.
