# Checklist de Submissão – Revista Interfaces

## Estrutura

* [ ] Artigo classificado como Artigo Original
* [ ] Título em português
* [ ] Título em inglês
* [ ] Resumo
* [ ] Palavras-chave
* [ ] Abstract
* [ ] Keywords
* [ ] Introdução
* [ ] Metodologia
* [ ] Resultados e Discussão
* [ ] Conclusão
* [ ] Agradecimentos
* [ ] Referências

---

## Formatação

* [ ] Papel A4
* [ ] Times New Roman 12
* [ ] Espaçamento duplo
* [ ] Margem superior 3 cm
* [ ] Margem esquerda 3 cm
* [ ] Margem inferior 2 cm
* [ ] Margem direita 2 cm
* [ ] Parágrafo 1,5 cm
* [ ] Texto justificado

---

## Extensão

* [ ] Entre 12 e 20 páginas

---

## Resumo

* [ ] Até 250 palavras
* [ ] Resumo em português
* [ ] Abstract em inglês
* [ ] Três palavras-chave
* [ ] Três keywords

---

## Ética

* [ ] Aprovação CEP informada
* [ ] Número do parecer informado
* [ ] CAAE informado

---

## Anonimização

* [ ] Sem nomes dos autores
* [ ] Sem afiliações
* [ ] Sem agradecimentos identificáveis
* [ ] Metadados removidos
* [ ] Autor do Word removido

---

## Figuras

* [ ] Citadas no texto
* [ ] Inseridas após citação
* [ ] Resolução 300 dpi
* [ ] Formato TIF

---

## Tabelas

* [ ] Citadas no texto
* [ ] Inseridas após citação
* [ ] Legendas adequadas

---

## Referências

* [ ] Ordem alfabética
* [ ] Estilo Autor-Data
* [ ] DOI incluído quando disponível
* [ ] Predomínio de referências dos últimos 5 anos

---

## Numeração

* [ ] Numeração contínua de linhas
* [ ] Numeração de páginas

---

## Submissão

* [ ] Carta ao editor preparada
* [ ] Todos os autores concordam com a submissão
* [ ] Manuscrito não submetido a outro periódico
